### 2. Function to Implement
```c
bool wasm_exec_function(const wasm_func_t *func, wasm_ctx_t *ctx, int32_t *out_val);
```
- Executes instructions in `func->code` sequentially starting with an empty evaluation stack (`sp = 0`).
- Instruction encoding:
  - `WASM_OP_I32_CONST <int32_t value>` (5 bytes total: 1 opcode + 4 bytes signed little-endian int32)
  - `WASM_OP_LOCAL_GET <uint8_t idx>` (2 bytes total)
  - `WASM_OP_LOCAL_SET <uint8_t idx>` (2 bytes total)
  - `WASM_OP_I32_LOAD <uint32_t offset>` (5 bytes total: 1 opcode + 4 bytes unsigned little-endian offset). Pops address `addr`, loads 4-byte int32 from `ctx->memory[addr + offset]`. Must return `false` (trap) if `addr + offset + 4 > WASM_MAX_MEM` or `addr < 0`.
  - `WASM_OP_I32_STORE <uint32_t offset>` (5 bytes total). Pops `value`, pops `addr`, stores 4-byte int32 at `ctx->memory[addr + offset]`. Must return `false` (trap) if out of bounds.
  - `WASM_OP_BLOCK` (1 byte): Opens a block scope.
  - `WASM_OP_LOOP` (1 byte): Opens a loop scope.
  - `WASM_OP_END` (1 byte): Closes a scope.
  - `WASM_OP_BR <uint8_t depth>` (2 bytes): Jumps out of `depth` enclosing scopes (`depth = 0` means current innermost block/loop).
    - If target scope is `BLOCK`, jump forward past its matching `END`.
    - If target scope is `LOOP`, jump backward to the `LOOP` opcode.
  - `WASM_OP_BR_IF <uint8_t depth>` (2 bytes): Pops condition `c`; if `c != 0`, performs branch just like `BR depth`.
- When reaching the final outer function end or completing execution, if `sp > 0`, writes top of stack to `*out_val` and returns `true`.
